Markdown

Data exported as a markdown file cannot be re-uploaded to the Story Outline Tool. It's only intended to be printed or used in a notes app once you're done organizing your story and want to use that data elsewhere. Markdown files can be opened in any text editor such as Notepad, Vim, and Emacs; and can be added to most notes apps.

Relays

Encrypted data is stored on these Nostr relays, one address per line.

The heck is a Nostr?

This app uses the Nostr protocol for optional synchronization. If you'd like to read more about the protocol, you can do so here. Otherwise, though, you can just ignore that fact. All data synced by this app is End-To-End encrypted, meaning that through some magical math nobody can ever read your data unless they have the sync code. If you ever lose it, you'll be unable to access your synced data; and if you ever give it to someone else, they'll be able to view and edit it just like you. Since the code uses math instead of my server (I don't even own any server you connect to, and will never be able to see your data) there is no way to reset or change your sync code, outside of generating a new one and re-uploading the database to that new one.
